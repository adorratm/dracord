# Mağaza inceleme (reviewer) notu

App Store / Play incelemesine yapıştırılacak kısa metin taslağı.

## Demo hesap

1. Seed veya elle oluşturduğun test kullanıcının e-posta + şifresini buraya yaz (secret; public repoya koyma).
2. Alternatif: Google ile giriş — reviewer’a geçici Google hesabı veya “Sign in with Google” + hazır sunucu daveti.

```
E-posta: (sen doldur)
Şifre: (sen doldur)
Demo sunucu daveti: https://dracord.com.tr/invite/...
```

## İncelemede denenecekler

- Google ile giriş
- Metin kanalı mesaj
- Ses kanalına katıl / ayrıl
- Ayarlar → Hesap Durumu → hesap silme yolu (silmeden vazgeçebilirler)

## Notlar

- Mikrofon / kamera izinleri ses için gereklidir.
- Arka plan ses: Android foreground service.
