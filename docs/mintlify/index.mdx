Dracord platform API’si ile bot oluşturabilir, slash komut senkronize edebilir, mesaj gönderebilir ve olayları Socket.IO gateway veya webhook ile alabilirsin.

## Ne bulursun?

- [Hızlı başlangıç](/quickstart) — uygulama + bot token + ilk mesaj
- [Keşif](/discovery) — base URL’i `/.well-known/dracord` ile öğren
- [Kimlik doğrulama](/authentication) — Bot token ve OAuth2
- [HTTP API](/http-api) — mesaj, komut, kullanıcı uçları
- [Bot Gateway](/bot-gateway) — canlı olay akışı
- [@dracord/bot-sdk](/bot-sdk) — TypeScript istemci

## Üretim uçları

| Kaynak | URL |
| --- | --- |
| API | `https://api.dracord.com.tr` |
| Discovery | `https://api.dracord.com.tr/.well-known/dracord` |
| OpenAPI | `https://api.dracord.com.tr/openapi.json` |
| Web (OAuth UI) | `https://dracord.com.tr` |

Uygulama ve bot token’ını **Ayarlar → Gelişmiş** (geliştirici modu) üzerinden oluşturursun. Token’ı yalnızca bir kez gösterilir; güvenli sakla.

<Note>
Bu site yalnızca üçüncü parti / bot geliştiricilerine yönelik kamuya açık API’yi anlatır. Sunucu işletimi, dağıtım ve dahili yönetim paneli burada yoktur.
</Note>
